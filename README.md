# Wolko Handcrafted Studio — E-Commerce & Free AI Voice Agent Automation

Handcrafted crochet flowers, bouquets, keychains, and hair accessories storefront with:
- **Customer Google Sign-Up & Checkout Form** (Name, Phone Number, Delivery Address)
- **Automatic Backend Google Sheets Order Sync** (`.CSV` live `=IMPORTDATA(...)` feed + Google Apps Script real-time Webhook)
- **5-Minute Automated Free AI Voice Calling Agent ("Aarohi")**
  - **Zero-Lag Hinglish Reflex Engine (<15ms)** with mid-sentence interruption (**Barge-In**) and mood sensing
  - **100% Free Offline SIM Calling** (`tel:+91...` direct SIM dialer + Free Android MacroDroid SIM Gateway)
  - Automatically updates order status to **`CONFIRMED ✅`** in Google Sheets when the customer replies *"Yes / Haan"*

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser. Click the **🔒 Admin** link at the bottom of the footer to access the Admin Google Sheets & Free AI Voice Agent Console.
